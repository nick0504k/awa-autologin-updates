# autologin extension — version feed

사내용 크롬 확장 프로그램의 **최신 버전 번호만** 게시하는 저장소입니다.

확장 프로그램은 하루 한 번 `version.json`을 읽어, 설치된 버전보다 높으면
아이콘에 배지를 띄우고 팝업에 내려받기 링크를 보여줍니다.

설치본과 소스는 비공개 저장소에 있으며 여기에는 포함되지 않습니다.

```json
{ "version": "1.5.0", "notes": "...", "download": "<설치본 주소>" }
```

`version`만 올리면 모든 사용자에게 업데이트 알림이 나갑니다.

`version.test.json`은 알림 동작을 점검할 때만 쓰는 파일입니다. 실제 배포 버전이 아니므로
확장 프로그램의 기본 확인 주소로는 절대 쓰지 마세요.
